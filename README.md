# 🌍 Areas - ASP.NET MVC Multi-Entity CRUD App

**Areas** is a practical ASP.NET MVC project designed to implement and manage CRUD operations for multiple entities including Country, State, City, Student, and Branch. It follows the MVC architecture and integrates RESTful API calls using HttpClient for data operations.

---

## 🚀 Features

- ✅ CRUD operations for:
  - Country 🌐
  - State 🏞️
  - City 🏙️
  - Student 🎓
  - Branch 🏢
- 🔗 RESTful API consumption via `HttpClient`
- 📦 Clean MVC architecture
- 🗃️ Entity Framework (DB First or Code First)
- 💾 SQL Server / LocalDB integration
- 🖼️ Razor Views for UI
- ⚙️ Visual Studio project setup

---

## 🛠️ Tech Stack

- 💻 ASP.NET MVC 5 / .NET Framework
- 🌐 HttpClient for API requests
- 🗃️ Entity Framework
- 💾 SQL Server / LocalDB
- 🖼️ Razor Pages
- ⚙️ Visual Studio
